Featured Project

An end-to-end analytics project, from data preparation to interpretation and decision-focused visualization.

Humanitarian Giving Observatory — Power BI Portfolio

Question & caveat

THE QUESTION

How well does reported funding cover global humanitarian funding requirements? Built from public UN OCHA Financial Tracking Service (FTS) data, 2000–2026.

THE CAVEAT

This is a descriptive financial analysis, not a measure of need or suffering. USD 140.37bn of reported funding sits on rows with blank requirements, so the headline ratio is not a row-matched rate.

I designed the full analytical pipeline: Power Query cleaning, a snowflake data model, six DAX measures, an executive dashboard, and a report that keeps every data-quality limit visible.

How I built it — each stage links to the repository or the live case study (Data):

01OCHA FTS source data 02Power Query, model & DAX 03Power BI file (.pbix) 04Analytical report (PDF) 05Python figure script 06Measure definitions 07Limitations 08Live case study →

What it showed — 2000–2026, aligned period:

Requirements USD 531.38bn
Reported funding USD 428.92bn
Coverage 80.72%
Funding gap USD 102.47bn
Annual coverage range 52.4% (2025) – 204.5% (2005)
Largest shortfalls Lebanon ≈$16.8bn, Syria ≈$13.5bn, Sudan ≈$12.3bn, DRC ≈$11.0bn

The 80.72% figure is the aligned 2000–2026 comparison; the live case study and Power BI dashboard also report an 81.08% all-record validation context, since a small amount of funding falls outside the requirement years. Both are shown side by side rather than picking one.
